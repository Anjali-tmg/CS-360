# CS-360
# Briefly summarize the requirements and goals of the app you developed. What user needs was this app designed to address?

For Project Three, I developed an Event Tracking App using Android Studio. The main goal of my app was to help users organize and keep track of important events, such as appointments, meetings, and personal activities. The app was designed to make it easier for users to manage their schedules and remember upcoming events. Some of the main requirements included creating a login screen, allowing users to add and manage events, storing event information, and providing notifications or reminders. I wanted to create an app that was simple, organized, and easy for users to understand.

# What screens and features were necessary to support user needs and produce a user-centered UI for the app? How did your UI designs keep users in mind? Why were your designs successful?

My Event Tracking App included important screens such as a login screen and an event display screen. The login screen allowed users to enter their username and password or create a new account. The event screen was designed to display event information and help users manage their schedules. I also worked on features for event reminders and notifications.

When designing the UI, I focused on keeping everything simple and easy to navigate. I used clear labels, buttons, and text fields so users could understand how to use the app without getting confused. I also tried to organize the screens so users could easily find the features they needed. I believe my design was successful because it focused on the main purpose of the app and made the layout easy to understand.

# How did you approach the process of coding your app? What techniques or strategies did you use? How could those techniques or strategies be applied in the future?

When I started coding my app, I worked on one part at a time instead of trying to complete everything at once. I used Android Studio and Java to develop the application. I started by creating the layouts using XML and then worked on connecting the screens and adding functionality. I also checked my code regularly to identify errors and make corrections.

One strategy that helped me was breaking larger tasks into smaller steps. Whenever I had a problem, I reviewed my code, checked the error messages, and tried to understand what needed to be fixed. This approach helped me stay organized throughout the project. In the future, I can use the same strategy when developing other applications because it makes coding easier to manage and helps reduce mistakes.

# How did you test to ensure your code was functional? Why is this process important, and what did it reveal?

To test my application, I used Android Studio's build tools and worked with the Android Emulator to check how the app functioned. I checked whether the screens displayed correctly, whether the buttons and text fields were placed properly, and whether the application had any coding errors. I also reviewed the event reminder and notification settings during development.

Testing is important because it helps developers identify problems before users start using the application. During this project, I learned that even small mistakes in the code or layout can affect how an app works. Testing helped me understand which parts needed improvement and why it is important to check the application throughout the development process instead of waiting until the end.

# Consider the full app design and development process from initial planning to finalization. Where did you have to innovate to overcome a challenge?

One challenge I experienced during this project was making sure the different parts of my app worked together correctly. Creating the UI was easier for me than adding the functionality because I had to understand how the Java code connected with the XML layouts. I also had to work through issues related to building the project and setting up the event reminder features.

To overcome these challenges, I tried different solutions, reviewed my code, and made changes step by step. Instead of starting over whenever something went wrong, I focused on finding the specific problem and correcting it. This experience taught me how important patience, problem-solving, and testing are in mobile app development.

# In what specific component of your mobile app were you particularly successful in demonstrating your knowledge, skills, and experience?

I believe I was particularly successful in designing the user interface for my Event Tracking App. I was able to create a login screen with username and password fields, buttons, and an organized layout. I also worked on the event display screen to make it easier for users to view and manage their event information.

This part of the project helped me demonstrate what I learned about Android Studio, XML layouts, and user-centered design. Before taking this course, I did not have much experience creating mobile applications. Now, I have a better understanding of how to plan an app, design its screens, write code, and test its functionality. Overall, Project Three helped me improve my technical skills and gave me more confidence to work on mobile application development projects in the future.
